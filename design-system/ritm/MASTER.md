# RITM — дизайн-система главной страницы (MASTER)

Источник правды для `src/Landing.jsx`. Собрана скиллом **ui-ux-pro-max** (`--design-system`, запрос
«fitness tracker app dark energetic», ручки variance 7 / motion 6 / density 3) и подогнана под бренд RITM.
Где решение отличается от выдачи скилла — причина указана.

## Паттерн
**Feature-Rich Showcase + Interactive Demo** (скилл: `Feature-Rich Showcase`, `product-demo-features`).
Порядок: Первый экран (сообщение + экран тренировки в телефоне + CTA) → лента-бегущая строка → цифры →
bento-сетка возможностей (у каждой карточки одна мысль) → заявление на видео → демо подхода → три шага →
прогресс → цены → установка → вопросы → лаймовый CTA-блок → подвал с документами.
Социальных доказательств (отзывы, рейтинги) нет намеренно: скилл требует только проверенные, выдумывать нельзя.
CTA: в шапке (всегда видна), на первом экране, после возможностей, в ценах и внизу.

## Стиль
**Dark Mode (OLED) + Bento Box Grid**, энергичные неоновые акценты. Скилл отмечает для фитнеса антипаттерны
«приглушённые цвета», «низкая энергия», «статичный дизайн» — поэтому лайм, крупная типографика, движение.

## Типографика
- Заголовки: **Sofia Sans Extra Condensed** 800–900, ВЕРХНИЙ РЕГИСТР, `line-height .86–.9`, `text-wrap: balance`.
  Скилл предложил пару Sports/Fitness (Barlow Condensed + Barlow), но в Barlow нет кириллицы; Sofia Sans
  Extra Condensed найден тем же скиллом (`--domain google-fonts`, «condensed display cyrillic»).
- Текст: **Onest** 400–600, 15–19 px, `line-height 1.55–1.65`.
- Размеры: первый экран `clamp(54px, 8.4vw, 124px)`, разделы `clamp(42px, 6.4vw, 84px)`, карточки 28–30 px.
- Русская типографика: тире и короткие предлоги («в», «с», «на», «до») привязаны неразрывным пробелом.

## Пространство и форма
Разделы 96–128 px по вертикали (density 3 — «просторно»). Карточки — радиус 24 px, кнопки — «таблетки».
Сетка bento: 4 колонки (≥1024) → 2 (≥768) → 1; большая карточка 2×2, широкие 2×1.

## Движение
- Карточки появляются «волной»: `opacity 0 → 1`, `translateY 16px`, `scale .92 → 1`, 450 мс,
  `cubic-bezier(.34,1.56,.64,1)` (≈ back.out(1.4)), шаг 60 мс.
- Блоки при прокрутке — снизу вверх 700–800 мс; наведение 150–250 мс (`scale 1.02` у карточек).
- Первый экран — CSS-анимации (играют из готового HTML до загрузки скриптов).
- Фоновые видео — lazy, пауза вне экрана, постер при «Экономии трафика»/2G/«Уменьшении движения».
- `prefers-reduced-motion`: все анимации выключены, показано итоговое состояние.
