# FORMA — Telegram Mini App (версия для Netlify)

Приложение для тренировок, бега, питания и привычек, которое открывается внутри Telegram.

## Что внутри

- `src/App.jsx` — всё приложение
- `netlify/functions/claude.mjs` — серверная функция по адресу `/api/claude`: проверяет подпись Telegram и отправляет фото или текст в Claude
- `netlify/functions/create-invoice.mjs` — создаёт ссылку на оплату в Telegram Stars
- `netlify/functions/telegram-webhook.mjs` — принимает события оплаты от Telegram
- `netlify.toml` — настройки сборки
- `.env.example` — список ключей, которые нужно указать в Netlify

## Если не работает распознавание еды
В приложении теперь показывается конкретная причина ошибки:
- «Сервер отклонил запрос» — приложение открыто не из Telegram, или неверные `BOT_TOKEN` / `ANTHROPIC_API_KEY` на хостинге. После изменения переменных обязательно сделай повторный деплой.
- «Сервер распознавания недоступен» — проверь ключ и что аккаунт Anthropic активен и доступен в твоей стране.
- «Не получилось разобрать ответ» — попробуй ещё раз; если повторяется, увеличь `CLAUDE_MAX_TOKENS` (например, до 8000) или укажи другую модель в `CLAUDE_MODEL`.
- Подробности всегда видны в логах функции `claude` на хостинге.

## Запуск на телефоне

### 1. Бот
1. В Telegram открой @BotFather и отправь `/newbot`.
2. Придумай имя и username, который заканчивается на `bot`.
3. Сохрани токен. Не загружай его в GitHub.

### 2. Код на GitHub
1. Создай репозиторий на github.com.
2. Нажми «uploading an existing file» и перетащи все файлы из этой папки, включая папку `netlify`.
   Скрытые файлы вроде `.gitignore` можно не загружать.

### 3. Netlify
1. Зайди на app.netlify.com через GitHub.
2. Add new project → Import an existing project → GitHub → выбери репозиторий.
   Настройки сборки подтянутся из `netlify.toml`.
3. Нажми Deploy.
4. Открой Site configuration → Environment variables → Add a variable и добавь:
   - `ANTHROPIC_API_KEY` — ключ из console.anthropic.com
   - `BOT_TOKEN` — токен из шага 1
   Если есть выбор Scopes, проверь, что включены Functions.
5. Deploys → Trigger deploy → Deploy site. Без повторного деплоя функция новых ключей не увидит.
6. Скопируй адрес вида `https://имя.netlify.app`. Имя можно поменять в Site configuration → Change site name.

Перетаскивание папки через Netlify Drop не подойдёт: так публикуется только статика, без серверной функции.

### 4. Привязка к боту
В @BotFather:
- `/mybots` → бот → Bot Settings → Menu Button → вставь адрес Netlify.
- По желанию `/newapp` → тот же адрес → короткое имя, чтобы приложение открывалось по ссылке `t.me/имя_бота/короткое_имя`.

### 5. Проверка
Открой бота на телефоне, нажми кнопку меню, пройди анкету и сфотографируй еду.

## Если что-то не работает
- Logs → Functions → `claude` покажет ошибки функции.
- Ошибка 401 вне Telegram — это нормально. Для проверки в браузере временно добавь `ALLOW_BROWSER_TESTING=1`, сделай деплой, а после проверки удали переменную.
- Ошибка 401 в Telegram — проверь `BOT_TOKEN`: это должен быть токен того же бота, из которого открыто приложение.

## Оплата звёздами Telegram

Код уже умеет создавать настоящий счёт в Stars и открывать его прямо в приложении (`netlify/functions/create-invoice.mjs`), но Telegram требует, чтобы бот сам отвечал на платёжные события — это делает `netlify/functions/telegram-webhook.mjs`.

1. После деплоя один раз пропиши боту адрес вебхука (замени `<TOKEN>` и `<домен>`):
```
curl "https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<домен>/api/telegram-webhook"
```
2. Проверить, что всё подключилось:
```
curl "https://api.telegram.org/bot<TOKEN>/getWebhookInfo"
```
3. Цены заданы в `netlify/functions/create-invoice.mjs` (`PLANS`) в звёздах: месяц — подписка с автопродлением (Telegram разрешает только период 30 дней), год — разовый платёж без автопродления.
4. Оплата подтверждается на телефоне сразу после оплаты (`Telegram.WebApp.openInvoice` возвращает статус `paid` прямо в приложение). Это удобно, но проверка держится на телефоне пользователя — для честной защиты от подделки статус стоит когда-нибудь сверять и на сервере, сохраняя `successful_payment` из вебхука в базу.
5. Отдельная оплата картой или через СБП **вне** этого мини-аппа возможна только на отдельном сайте — внутри Telegram цифровые товары продаются только за Stars.

## Расчёт калорий и БЖУ

Норма считается в `src/nutrition.js` по методике «Расчёт калорий и БЖУ»:

1. Основной обмен — формула Миффлина–Сан Жеора. Если в анкете или настройках указан процент жира, используется формула Кэтча–Макардла. Харрис–Бенедикт показывается для сравнения.
2. Суточный расход = основной обмен × коэффициент активности (1,2 / 1,375 / 1,55 / 1,725 / 1,9), его человек выбирает в анкете.
3. Поправка под цель: снижение веса −10, −15 или −20%, набор +5, +10 или +15%, иначе поддержание. До 18 лет поправка не больше 10%. Ниже основного обмена норма не опускается.
4. Белок 1,8 г/кг (1,4 г/кг для цели «выносливость»), жиры 0,9 г/кг в пределах 20–35% калорийности, углеводы — остаток: (ккал − Б × 4 − Ж × 9) / 4. При ИМТ 30 и выше белок и жиры считаются на целевой вес.

Пошаговый расчёт виден в «Питании» → «Как посчитана норма». Проверка формул на примере из методики (мужчина, 35 лет, 180 см, 85 кг → 2380 ккал, Б 153 / Ж 76 / У 271): `npm test`.

## Обновления
Загружаешь изменённые файлы в GitHub, и Netlify сам пересобирает сайт.

## Запуск на компьютере
```
npm install
npm install -g netlify-cli
netlify dev
```
Обычный `npm run dev` запускает только интерфейс, без `/api/claude`.

## Что пока работает только в демо-режиме
- Данные хранятся на устройстве, на другом телефоне их не будет — в том числе купленная Pro-подписка.
- Лимит 3 распознавания в день и Pro-статус проверяются в приложении на телефоне, а не на сервере. Для честной защиты от подделки нужна база данных, которая хранит статус подписки и сверяется при каждом запуске.


## Документы для согласования платежей

В Mini App добавлен раздел **«Документы и оплата»** в настройках:
- Политика конфиденциальности — постоянная кнопка со ссылкой на документ.
- Пользовательское соглашение — постоянная кнопка со ссылкой на документ.
- Тарифы и стоимость — 150 ⭐/месяц и 1200 ⭐/12 месяцев.
- Контакты поддержки — `@doltiii`.
- Временное кодовое слово для проверки — `Plaтега`.

Перед согласованием проверь, что тексты документов на Telegraph содержат только актуальные данные проекта и актуальную дату. Персональные данные, ИП/ООО/ИНН и аналогичные реквизиты не добавляются в интерфейс Mini App.

При командах `/start`, `/legal` или сообщении «документы» бот также показывает тарифы, поддержку, кодовое слово и кнопки юридических документов.
