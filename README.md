# ОГЭ Квест — Telegram Mini App для подготовки к ОГЭ по математике

Игровое приложение внутри Telegram: ребёнок проходит путь по заданиям ОГЭ, решает лёгкие примеры, разбирает задачи по шагам и пишет пробные варианты. Есть подписка за 150 ₽ в месяц.

## Что умеет

- **Разминка**: лёгкие примеры по 8 навыкам (таблица умножения, дроби, проценты, отрицательные числа…) и «Блиц» на 60 секунд.
- **Путь к ОГЭ**: карта из 15 тем, которые покрывают задания 1–19 первой части. В каждой теме есть шпаргалка, пошаговый разбор («показать следующий шаг») и тренировка из 10 заданий с объяснением каждой ошибки.
- **Пробные варианты**: 19 заданий с таймером, оценка по шкале ФИПИ с учётом геометрии, разбор каждого ответа.
- **Вторая часть (20–25)**: задачи с полным решением и критериями. Ребёнок сам выставляет себе баллы, как эксперт на экзамене.
- **Игра**: опыт (XP), уровни, серия дней 🔥, цель на день, комбо за ответы подряд, звёзды за темы, 11 достижений, конфетти, вибрация, талисман — совёнок Огуша.
- **Источники**: ссылки на открытый банк ФИПИ, демоверсии, навигатор ФИПИ, РешуОГЭ и РЭШ. Они открываются в браузере Telegram.
- **Прогресс** хранится в облаке Telegram (CloudStorage), поэтому сохраняется на всех устройствах ребёнка.
- Светлая и тёмная тема подстраиваются под Telegram.

### Откуда задания
Задания составлены по образцу открытого банка ФИПИ и **генерируются автоматически**: каждый раз новые числа, поэтому заданий бесконечно много. Тексты с сайтов ФИПИ и РешуОГЭ в приложение не копируются: у этих сайтов свои права на материалы. Вместо этого в каждой теме и в профиле стоят прямые ссылки на них.

## Запуск

### 1. Бот
1. В Telegram открой @BotFather и отправь `/newbot`.
2. Сохрани токен. Не загружай его в GitHub.

### 2. Netlify
1. app.netlify.com → Add new project → Import an existing project → GitHub → выбери этот репозиторий. Настройки сборки подтянутся из `netlify.toml`.
2. Site configuration → Environment variables. Добавь переменные из `.env.example`. Минимум нужны `BOT_TOKEN` и `APP_URL` (адрес вида `https://имя.netlify.app`).
3. Deploys → Trigger deploy. Функции видят новые переменные только после повторного деплоя.

Подписки хранятся в **Netlify Blobs**. Это встроенное хранилище, отдельная база данных не нужна.

### 3. Привязка к боту
1. В @BotFather: `/mybots` → бот → Bot Settings → Menu Button → вставь адрес Netlify.
2. Пропиши вебхук, чтобы бот отвечал на `/start` и принимал оплату (подставь свои значения):
```
curl "https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<домен>/api/telegram-webhook&secret_token=<TELEGRAM_WEBHOOK_SECRET>"
```

### 4. Оплата 150 ₽: карта и СБП через ЮKassa
1. Зарегистрируй магазин на yookassa.ru (нужен самозанятый, ИП или ООО).
2. Интеграция → Ключи API: скопируй `shopId` и секретный ключ в `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`.
3. Интеграция → HTTP-уведомления: адрес `https://<домен>/api/yookassa-webhook?secret=<YOOKASSA_WEBHOOK_SECRET>`, событие `payment.succeeded`.
4. Если в ЮKassa включены чеки по 54-ФЗ, укажи `RECEIPT_EMAIL`.

Ребёнок (или родитель) нажимает «Карта или СБП · 150 ₽» и платит на странице ЮKassa. Сервер получает уведомление, **повторно запрашивает платёж у ЮKassa** и только после этого включает PRO на 30 дней. Подделать оплату с телефона нельзя. Оплата картой или СБП не продлевается сама: через месяц нужно оплатить снова.

### 5. Оплата Telegram Stars (необязательно)
Работает сразу, если задан `BOT_TOKEN`. Цена — `PRICE_STARS`, по умолчанию 100 ⭐. Покупатель платит за звёзды по-разному в зависимости от платформы, а вывод идёт по курсу Telegram, поэтому подбери цену сам. Подписка Stars продлевается автоматически каждые 30 дней. Для ботов со Stars Telegram требует команду `/paysupport`, она уже есть; контакт задаётся в `SUPPORT_CONTACT`.

> Правила Telegram: цифровые товары внутри мини-приложений нужно продавать за Stars. Оплата картой через ЮKassa — внешняя ссылка, и её модерация остаётся на твоей ответственности. Если нужно строго по правилам, оставь только Stars: не задавай ключи ЮKassa, и кнопка карты исчезнет сама.

## Разработка

```
npm install
npm test            # проверка генераторов заданий
npm install -g netlify-cli
netlify dev         # интерфейс + серверные функции
```
`npm run dev` запускает только интерфейс, без `/api/*`. Для проверки в обычном браузере временно поставь `ALLOW_BROWSER_TESTING=1`, а после проверки удали.

## Шкала оценок
По рекомендации ФИПИ: максимум 31 балл; «3» — от 8, «4» — от 15, «5» — от 22. Из этих баллов не меньше 2 должно быть за геометрию. Регион может немного менять шкалу, поэтому её стоит сверять с демоверсией на fipi.ru каждый год.
