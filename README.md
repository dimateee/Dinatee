# Dinatee

## Джарвис — голосовой помощник для macOS и Windows

Говорите «Джарвис, …» — он распознаёт речь, выполняет команду на компьютере и отвечает голосом.

Что умеет:

- запускать и закрывать программы, открывать сайты и поиск в браузере;
- работать с файлами: открыть папку в Finder / проводнике, найти, прочитать, создать, переместить, удалить в корзину;
- громкость, пауза и переключение треков, снимок экрана, блокировка экрана, горячие клавиши, ввод текста;
- отвечать на вопросы и искать свежую информацию в интернете (погода, новости, факты);
- выполнять команды оболочки — только после вашего «да».

Как устроен: микрофон → faster-whisper (распознавание, локально) → Claude с инструментами → ElevenLabs или системный голос.

### Установка

Нужен Python 3.10–3.13 и ключ Claude API (https://console.anthropic.com).

macOS:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # впишите ANTHROPIC_API_KEY
python -m jarvis
```

Windows (PowerShell):

```powershell
py -m venv .venv; .venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env      # впишите ANTHROPIC_API_KEY
python -m jarvis
```

При первом запуске скачивается модель распознавания речи (около 500 МБ для `small`).

Разрешения macOS (Системные настройки → Конфиденциальность и безопасность) для терминала, из которого запускаете: «Микрофон»; «Универсальный доступ» — для горячих клавиш и ввода текста; «Запись экрана» — для снимков экрана.

### Режимы

- `python -m jarvis` — голосовой режим;
- `python -m jarvis --text` — команды с клавиатуры, удобно для проверки без микрофона;
- `python -m jarvis --devices` — список аудиоустройств.

После ответа Джарвис несколько секунд слушает продолжение без слова «Джарвис». «Джарвис, отключись» завершает работу.

### Голос

С `ELEVENLABS_API_KEY` в `.env` говорит голосом ElevenLabs (другой голос — `ELEVENLABS_VOICE_ID`). Без ключа используется системный голос: на macOS — Milena, на Windows — русский голос, если установлен русский языковой пакет.

### Настройки

Все параметры с пояснениями — в `.env.example`: модель и скорость ответа, чувствительность микрофона, размер модели распознавания, подтверждение опасных действий.

### Безопасность

Команды оболочки, удаление и перезапись файлов выполняются только после голосового подтверждения. Удаление — всегда в корзину. Отключить подтверждения можно через `JARVIS_CONFIRM=off`, но тогда ошибка распознавания может запустить не ту команду.
