# Pyexdg — сайт-магазин

Тёмный радужный сайт-витрина: каталог с фильтрами и поиском, корзина и оформление заказа в Telegram, контакты (Telegram, канал, почта, TikTok, YouTube). Сайт статический, собирать его не нужно.

## Что где лежит

- `js/config.js` — **всё, что вы меняете**: название, тексты, ссылки, товары и цены.
- `images/products/` — фото товаров.
- `index.html`, `css/style.css`, `js/app.js` — сам сайт. Их трогать не нужно.

## Как поменять товары и цены (можно с телефона)

1. Откройте на GitHub файл `js/config.js` и нажмите карандаш (Edit).
2. Найдите блок `products`. Каждый товар выглядит так:
   ```js
   {
     id: "hoodie-aurora",
     name: "Худи Aurora",
     price: 4990,
     oldPrice: 5990,          // необязательно: старая цена, скидка посчитается сама
     category: "Одежда",
     image: "images/products/hoodie.jpg",
     badge: "Хит",            // необязательно
     description: "Короткое описание товара.",
     soldOut: true,           // необязательно: «нет в наличии»
   },
   ```
3. Чтобы добавить товар, скопируйте блок от `{` до `},` и поменяйте значения. `id` у каждого товара должен быть свой.
4. Нажмите **Commit changes**. Через минуту сайт обновится.

Главное: текст в кавычках, цена числом без пробелов, после каждого товара запятая.

## Как добавить фото

1. Откройте папку `images/products` на GitHub → **Add file → Upload files** → загрузите фото (лучше вертикальные, примерно 4:5, например 800×1000).
2. В `js/config.js` у товара напишите путь: `image: "images/products/имя-файла.jpg"`.

## Как вставить ссылки

В `js/config.js` в блоке `contacts`:

```js
contacts: {
  telegram: "@username",                      // сюда же приходят заказы из корзины
  channel: "https://t.me/имя_канала",
  email: "name@mail.ru",
  avito: "https://www.avito.ru/...",          // ссылка на профиль Авито
  tiktok: "https://www.tiktok.com/@имя",
  youtube: "https://www.youtube.com/@имя",
},
```

Пустое поле показывается на сайте как «скоро».

## Как работает заказ

Покупатель кладёт товары в корзину и нажимает «Оформить в Telegram». Открывается чат с вами (`contacts.telegram`) с готовым сообщением: список товаров, количество и итоговая сумма. Покупателю остаётся нажать «Отправить». Корзина запоминается в браузере покупателя.

## Публикация на Netlify

1. app.netlify.com → **Add new project → Import an existing project → GitHub** → выберите этот репозиторий.
2. Настройки подтянутся из `netlify.toml` (сборка не нужна, публикуется корень). Нажмите **Deploy**.
3. После каждого изменения на GitHub Netlify обновит сайт сам.

## Проверить у себя на компьютере

```
python3 -m http.server 8000
```

и откройте http://localhost:8000.
