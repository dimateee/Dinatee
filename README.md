# Окраина — колония в духе RimWorld для Telegram

Мини-приложение Telegram: колония-симулятор, вдохновлённый RimWorld. Колонисты потерпели крушение на дикой планете — им нужно построить дом, вырастить еду, пережить зиму и отбиться от налётчиков. Вы не управляете каждым шагом: колонисты сами работают по приоритетам, а вы строите, отдаёте приказы и принимаете решения.

Игра открывается прямо в Telegram, управляется пальцами и сохраняется в облаке Telegram, поэтому прогресс доступен с любого устройства.

## Что есть в игре

- **Карта 80×80**, которая каждый раз генерируется заново: горы с залежами стали, серебра и старых механизмов, озёра, река, леса, ягодные кусты, дикие животные.
- **Колонисты** с навыками (9 штук), чертами характера, предысторией, настроением и нуждами (еда, сон, тепло, здоровье). При плохом настроении случаются нервные срывы.
- **Работы с приоритетами 1–4**, как в RimWorld: врач, надзор, готовка, охота, стройка, растения, рубка, шахта, переноска, наука.
- **Строительство**: деревянные и каменные стены (рисуются контуром комнаты), двери, кровати, столы, костёр, кухонная плита, стол учёного, факелы, дровяная печь, мешки с песком, турель, полы.
- **Зоны**: склады с фильтрами и поля (рис, картофель, кукуруза, целебный корень).
- **Приказы**: добыча камня и руды, рубка, сбор урожая, охота, разбор построек.
- **Времена года и погода**: весна, лето, осень и зима (урожай гибнет), дождь, снег, туман, смена дня и ночи с освещением от костров и факелов.
- **Температура в комнатах**: закрытая комната со стенами и дверью держит тепло, костёр и печь греют.
- **Рассказчик**: налёты, бешеные стаи, торговые караваны, грузовые капсулы, метеориты с рудой, похолодания, болезни растений, новые колонисты. Три уровня сложности.
- **Бой**: кнопка «В бой» призывает всех колонистов. Нажмите на землю — отряд пойдёт туда, нажмите на врага — атакует. Работают укрытия, кровотечение, лечение и спасение раненых.
- **Пленные**: раненого врага можно взять в плен и уговорить присоединиться к колонии.
- **Торговля** с караванами за серебро и **исследования** с открытием новых построек и культур.
- **Обучение**: подсказки «что делать дальше» и предупреждения о нехватке еды и дерева.

## Как играть

- Один палец двигает карту, два пальца меняют масштаб.
- Нажмите на колониста, постройку, предмет или клетку — внизу появится карточка с подробностями и кнопками.
- **Строить**: выберите постройку и проведите пальцем по карте. Пока выбран инструмент, карту двигают двумя пальцами.
- **Зоны → Склад** — первым делом, иначе вещи будут валяться где попало.
- Кровати, костёр и поле — в первый же день. Окружите кровати стенами с дверью, чтобы получилась тёплая спальня.
- Зима наступает на 26-й день. Заранее запасите еду и дрова.
- При налёте игра ставится на паузу. Нажмите «⚔ В бой», расставьте отряд и продолжайте.

## Запуск в Telegram (без программирования)

Понадобятся аккаунты на GitHub и Netlify (бесплатно).

### 1. Создайте бота

1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте имя и username, который заканчивается на `bot`.
3. Сохраните токен. Никому его не показывайте и не загружайте в GitHub.

### 2. Опубликуйте игру на Netlify

1. Зайдите на [app.netlify.com](https://app.netlify.com) через GitHub.
2. **Add new project → Import an existing project → GitHub** → выберите этот репозиторий и ветку.
3. Настройки сборки подтянутся из `netlify.toml` (`npm run build`, папка `dist`). Нажмите **Deploy**.
4. Через минуту появится адрес вида `https://имя.netlify.app`. Имя можно поменять: **Site configuration → Change site name**.

Подойдёт и любой другой хостинг статических сайтов с HTTPS (GitHub Pages, Vercel, Cloudflare Pages): нужно собрать проект командой `npm run build` и выложить папку `dist`.

### 3. Привяжите игру к боту

В @BotFather:

- `/mybots` → ваш бот → **Bot Settings → Menu Button** → вставьте адрес Netlify. Теперь в чате с ботом появится кнопка, которая открывает игру.
- По желанию: `/newapp` → тот же адрес → короткое имя. Игра будет открываться по ссылке `t.me/имя_бота/короткое_имя`, ей можно делиться с друзьями.

### 4. Кнопка «Играть» по команде /start (необязательно)

Если хотите, чтобы бот отвечал на `/start` сообщением с кнопкой «Играть»:

1. В Netlify: **Site configuration → Environment variables** → добавьте `BOT_TOKEN` (токен из шага 1). По желанию добавьте `WEBHOOK_SECRET` — любую случайную строку.
2. **Deploys → Trigger deploy → Deploy site**, чтобы функция увидела переменные.
3. Один раз пропишите боту адрес вебхука (замените `<TOKEN>`, `<домен>` и `<СЕКРЕТ>`; если секрет не задавали, уберите `&secret_token=...`):

```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<домен>/api/bot&secret_token=<СЕКРЕТ>
```

Откройте эту ссылку в браузере: ответ `"ok":true` означает, что всё подключено.

## Запуск на компьютере

Нужен Node.js 20 или новее.

```
npm install
npm run dev      # игра на http://localhost:5173 (откроется и в обычном браузере)
npm test         # автотесты симуляции: стройка, бой, торговля, плен, сохранения, год жизни колонии
npm run build    # сборка в папку dist
```

Вне Telegram игра работает как обычный сайт: прогресс сохраняется в браузере.

## Сохранения

- Игра сохраняется автоматически каждый игровой день и при сворачивании Telegram, а также вручную через меню.
- Копия сохраняется в браузере устройства и в облаке Telegram (CloudStorage: сжатое сохранение разбивается на части по 4000 символов). При запуске загружается более свежая из двух.
- Если колония погибла, сохранение удаляется — как в режиме «одной жизни» RimWorld.

## Устройство проекта

```
index.html                 страница, подключение Telegram Web App SDK
src/main.js                игровой цикл, камера, инструменты, приказы
src/telegram.js            обёртка Telegram API: тема, отступы, вибрация, «Назад», облако
src/storage.js             сохранения в браузере и облаке Telegram
src/styles.css             стили интерфейса
src/ui/ui.js               панели, карточки объектов, окна, главное меню
src/ui/input.js            касания: карта, щипок, рисование инструментом
src/render/renderer.js     отрисовка карты, освещения, погоды и эффектов на canvas
src/render/sprites.js      процедурная графика: всё рисуется кодом, без картинок
src/game/defs.js           все определения и баланс: постройки, растения, оружие, исследования
src/game/world.js          мир: клетки, предметы, постройки, зоны, комнаты, температура
src/game/mapgen.js         генерация карты и высадка колонии
src/game/path.js           поиск пути A*
src/game/pawn.js           колонисты: нужды, здоровье, настроение, срывы
src/game/jobs.js           работы колонистов и их выполнение
src/game/ai.js             бой отряда, налётчики, животные, торговцы, пленные
src/game/combat.js         стрельба, ближний бой, урон, турели
src/game/story.js          рассказчик: события, налёты, торговля
src/game/save.js           сохранение и загрузка мира
netlify/functions/bot.mjs  необязательный ответ бота на /start
tests/sim.test.js          автотесты симуляции (запуск без браузера)
```

Баланс удобно менять в `src/game/defs.js`: скорость дня (`TPH`), стоимость построек, урожайность, оружие, частоту угроз на каждом уровне сложности (`DIFFICULTY`).

## Если что-то не работает

- **Белый экран или ошибка при открытии в Telegram.** Проверьте, что адрес в BotFather начинается с `https://` и совпадает с адресом сайта.
- **Не появилась кнопка «Играть» после /start.** Проверьте `BOT_TOKEN` и сделайте повторный деплой. Ответ вебхука смотрите через `https://api.telegram.org/bot<TOKEN>/getWebhookInfo`, ошибки функции — в Netlify: **Logs → Functions → bot**.
- **Прогресс не переносится между устройствами.** Облако Telegram доступно в приложениях Telegram с поддержкой Bot API 6.9 и новее. Обновите Telegram.
