# Pyexdg — сайт-магазин и Telegram-бот

Тёмный радужный магазин: каталог с фильтрами и поиском, корзина, заявка «Под заказ», контакты (Telegram, канал, почта, Авито, TikTok, YouTube). Тот же сайт открывается внутри Telegram как мини-апп бота: заказы и заявки сразу приходят вам от бота, а вы отвечаете покупателям прямо в боте.

Сайт поделён на экраны-вкладки: **Главная · Каталог · Заявка · Корзина · Контакты**. На телефоне и в мини-аппе вкладки внизу, на компьютере в шапке. На Главной: приветствие, «Хиты и новинки» (товары с наклейкой `badge` идут первыми), «Как заказать» и кнопка «Под заказ».

## Что где лежит

- `public/js/config.js` — **всё, что вы меняете**: название, тексты, ссылки, товары и цены. Бот берёт товары и ссылки из этого же файла.
- `public/images/products/` — фото товаров.
- `public/index.html`, `public/css/style.css`, `public/js/app.js` — сам сайт. Их трогать не нужно.
- `netlify/functions/` — бот: приём заказов (`order.mjs`), сообщения боту (`telegram-webhook.mjs`), подключение бота (`telegram-setup.mjs`).

## Как поменять товары и цены (можно с телефона)

1. Откройте на GitHub файл `public/js/config.js` и нажмите карандаш (Edit).
2. Найдите блок `products`. Каждый товар выглядит так:
   ```js
   {
     id: "hoodie-aurora",
     name: "Худи Aurora",
     price: 4990,
     oldPrice: 5990,          // необязательно: старая цена, скидка посчитается сама
     category: "Одежда",
     image: "images/products/hoodie.jpg",
     badge: "Хит",            // необязательно
     description: "Короткое описание товара.",
     soldOut: true,           // необязательно: «нет в наличии»
   },
   ```
3. Чтобы добавить товар, скопируйте блок от `{` до `},` и поменяйте значения. `id` у каждого товара должен быть свой.
4. Нажмите **Commit changes**. Через минуту сайт и бот обновятся.

Главное: текст в кавычках, цена числом без пробелов, после каждого товара запятая.

## Как добавить фото

1. Откройте папку `public/images/products` на GitHub → **Add file → Upload files** → загрузите фото (лучше вертикальные, примерно 4:5, например 800×1000).
2. В `public/js/config.js` у товара напишите путь: `image: "images/products/имя-файла.jpg"`.

## Как вставить ссылки

В `public/js/config.js` в блоке `contacts`:

```js
contacts: {
  telegram: "@username",                      // на сайте сюда приходят заказы из корзины
  channel: "https://t.me/имя_канала",
  email: "name@mail.ru",
  avito: "https://www.avito.ru/...",          // ссылка на профиль Авито
  tiktok: "https://www.tiktok.com/@имя",
  youtube: "https://www.youtube.com/@имя",
},
```

Пустое поле показывается на сайте как «скоро», а в боте такой кнопки просто нет.

## Как работает заказ

**На сайте.** Покупатель кладёт товары в корзину и нажимает «Оформить в Telegram». Открывается чат с вами (`contacts.telegram`) с готовым сообщением, покупателю остаётся нажать «Отправить».

**В боте (мини-апп).** Покупатель нажимает «Оформить заказ», и всё. Бот сразу присылает вам заказ: товары, сумму и кто заказал. Покупатель получает «Заказ принят ✅». Цены бот пересчитывает сам по `config.js`, поэтому подменить цену нельзя.

## Заявки «Под заказ»

Если нужной вещи нет в каталоге, покупатель заполняет форму: что нужно, бренд, размер, цвет, бюджет, ссылку на пример и подробности. На сайте открывается чат с готовым текстом, в боте заявка приходит вам сразу. Слова-подсказки над полем «Что нужно» меняются в `public/js/config.js`, в строке `requestExamples`.

## Как отвечать покупателям через бота

- Заказы, заявки и любые сообщения покупателей приходят вам от бота с меткой вида `#u123456789`.
- Нажмите **«Ответить»** на таком сообщении и напишите текст (можно фото или голосовое). Бот перешлёт ответ покупателю и напишет «✓ Отправлено покупателю».
- Это работает, даже если у покупателя нет @имени.

## Публикация на REG.RU (сайт и бот вместе, свой домен)

На обычном хостинге REG.RU работает PHP, поэтому бот здесь — PHP-версия в папке `regru/api/` с той же логикой, что и на Netlify. Сайт тот же. Товары по-прежнему меняются в одном файле `js/config.js`, а цены бот пересчитывает сам. Архив для загрузки собирает команда `bash regru/build.sh` (появится `dist/pyexdg-regru.zip`).

1. **Домен и хостинг.** На reg.ru закажите хостинг для сайтов на PHP (подойдёт самый простой тариф) и домен, например `pyexdg.ru`. Если покупать вместе, домен сам привяжется к хостингу; иногда это занимает несколько часов.
2. **Версия PHP.** В панели хостинга (ISPmanager): **Сайты** → ваш домен → **Изменить** → версия PHP **8.1 или новее**.
3. **HTTPS.** **SSL-сертификаты** → выпустите бесплатный **Let's Encrypt** для домена (и `www`). В настройках сайта включите **перенаправление HTTP на HTTPS**. Без HTTPS мини-апп в Telegram не откроется.
4. **Файлы.** **Менеджер файлов** → папка сайта (обычно `www/pyexdg.ru`). Удалите стандартную заглушку `index.html`, **закачайте** `pyexdg-regru.zip`, выделите его и нажмите **Извлечь**. В папке сайта должны оказаться `index.html`, `css`, `js`, `images` и `api` (внутри `api` есть скрытый файл `.htaccess`, он нужен).
5. **Секреты.** В папке `api` скопируйте `config.example.php` под именем `config.php`, откройте его (**Редактировать**) и впишите:
   - `BOT_TOKEN` — токен от @BotFather;
   - `WEBHOOK_SECRET` — слово латиницей от 8 символов;
   - `ADMIN_CHAT_ID` — ваш chat id (команда `/myid` в боте);
   - `SITE_URL` — `https://pyexdg.ru`.
6. **Проверьте сайт:** откройте `https://pyexdg.ru`.
7. **Подключите бота** (переключит его на REG.RU): откройте `https://pyexdg.ru/api/telegram-setup?key=ВАШ_СЕКРЕТ`. Если страница не найдена, откройте тот же адрес с `.php`: `.../api/telegram-setup.php?key=...`. Должны быть зелёные галочки.
8. **Проверьте в боте:** `/start` → «Открыть магазин» → корзина → «Оформить заказ». Заказ должен прийти вам от бота.

**Как обновлять товары:** **Менеджер файлов** → `js/config.js` → **Редактировать** прямо в панели. Новые фото закачивайте в `images/products`.

**Если что-то не так:** ошибки PHP видны в ISPmanager в журналах сайта (`error.log`). Файлы `api/config.php` и `api/lib.php` снаружи не открываются, это нормально.

## Публикация в Yandex Cloud (без значка Netlify, стабильно в России)

Схема: файлы сайта лежат в бакете **Object Storage**, бот работает в **Cloud Functions**, а **API Gateway** отдаёт и то и другое по одному адресу `https://….apigw.yandexcloud.net`. Обычный магазин укладывается в бесплатные лимиты: 1 млн вызовов функций и 100 000 запросов к шлюзу в месяц.

Архивы для загрузки собирает команда `bash yandex/build.sh` (появятся в папке `dist/`): `pyexdg-yandex-site.zip` — сайт, `pyexdg-yandex-function.zip` — бот.

1. **Аккаунт.** Зайдите на console.yandex.cloud через Яндекс ID, создайте платёжный аккаунт (карта российского банка) и каталог, например `default`.
2. **Бакет с сайтом.** Object Storage → **Создать бакет**:
   - имя латиницей, например `pyexdg-shop` (должно быть уникальным);
   - **Доступ на чтение объектов: Публичный**, остальное — Ограниченный, класс — Стандартное.
   
   Откройте бакет и загрузите файлы из `pyexdg-yandex-site.zip` с сохранением папок: `index.html`, `favicon.svg`, папки `css`, `js`, `images/products`. Если папка не загружается целиком, создайте её кнопкой **Создать папку** и загрузите файлы внутрь.
3. **Функция бота.** Cloud Functions → **Создать функцию** → имя `pyexdg-bot`:
   - **Редактор** → среда **Node.js 22** (примеры кода не добавлять);
   - способ: **ZIP-архив** → загрузите `pyexdg-yandex-function.zip`;
   - точка входа `index.handler`, таймаут `10`, память `128 МБ`;
   - переменные окружения: `BOT_TOKEN` и `WEBHOOK_SECRET` (см. ниже), нажмите **Сохранить изменения**.
   
   На странице функции включите **Публичная функция** и скопируйте её **идентификатор**.
4. **API-шлюз.** API Gateway → **Создать API-шлюз** → имя `pyexdg`. В поле спецификации вставьте текст из `yandex/api-gateway.yaml`, заменив `ИМЯ_БАКЕТА` и `ID_ФУНКЦИИ` (везде). Нажмите **Создать** и скопируйте **служебный домен** вида `https://d5d….apigw.yandexcloud.net`.
5. **Адрес сайта для бота.** В функции добавьте переменную `SITE_URL` = этот домен и снова сохраните. Откройте домен в браузере: должен открыться магазин.
6. **Подключение бота.** Откройте `https://d5d….apigw.yandexcloud.net/api/telegram-setup?key=ВАШ_СЕКРЕТ`. Появится страница с галочками, кнопка «Магазин» в боте начнёт открывать новый адрес.
7. **Куда слать заказы.** Напишите боту `/myid`, добавьте в функцию переменную `ADMIN_CHAT_ID` с этим числом и сохраните.
8. **Проверка.** `/start` → «Открыть магазин» → корзина → «Оформить заказ». Если делали прямую ссылку через `/newapp`, поменяйте в ней адрес: @BotFather → `/myapps` → бот → изменить ссылку.

**Как обновлять товары на Яндексе:** поменяйте `public/js/config.js` (или пришлите данные), затем загрузите новый `config.js` в папку `js` бакета с заменой. Новые фото кладите в `images/products` бакета. Код бота меняется загрузкой нового `pyexdg-yandex-function.zip` в функцию.

## Подключение бота на Netlify (другой вариант)

1. **Создайте бота.** В Telegram откройте @BotFather → `/newbot` → придумайте имя и username, который заканчивается на `bot`. Сохраните токен и никому его не присылайте. Аватарку можно поставить командой `/setuserpic`.
2. **Подключите GitHub к Netlify.** Функции бота работают, только если сайт публикуется из GitHub (перетаскивание папки в Netlify Drop их не запускает). В проекте **pyexdg** на app.netlify.com: **Project configuration → Build & deploy → Link repository** → GitHub → `dimateee/Dinatee` → ветка, в которой лежит этот код. Остальные настройки подтянутся из `netlify.toml`.
3. **Добавьте переменные.** **Project configuration → Environment variables** (список есть в `.env.example`):
   - `BOT_TOKEN` — токен из шага 1;
   - `WEBHOOK_SECRET` — любое слово из латиницы и цифр, от 8 символов, например `pyexdg_secret_2026`.
4. **Задеплойте.** **Deploys → Trigger deploy → Deploy project**.
5. **Подключите бота к сайту.** Один раз откройте в браузере ссылку (вместо `ВАШ_СЕКРЕТ` подставьте `WEBHOOK_SECRET`):
   ```
   https://pyexdg.netlify.app/api/telegram-setup?key=ВАШ_СЕКРЕТ
   ```
   Появится страница с галочками: вебхук, команды, кнопка «Магазин» и описание бота.
6. **Укажите, кому слать заказы.** Напишите своему боту `/myid`, скопируйте число, добавьте переменную `ADMIN_CHAT_ID` с этим числом и снова сделайте **Trigger deploy**.
7. **Проверьте.** Откройте бота, нажмите «Запустить» → «🛍 Открыть магазин», положите товар в корзину и нажмите «Оформить заказ». Заказ должен прийти вам от бота.

По желанию:
- в @BotFather → `/newapp` можно сделать прямую ссылку на мини-апп вида `t.me/имя_бота/shop`;
- отключите значок «Powered by Netlify» (**Project configuration → General → Powered by Netlify badge**), иначе он появится и в мини-аппе.

## Если что-то не работает

- **Бот молчит на /start.** Откройте ссылку настройки из шага 5 ещё раз и проверьте, что все пункты с галочкой.
- **Заказ не приходит.** Проверьте `ADMIN_CHAT_ID` и сделайте Redeploy после изменения переменных. Если бот недоступен, мини-апп сам откроет чат с готовым текстом заказа.
- **Ошибки.** Подробности видны в Netlify → **Logs → Functions**.
