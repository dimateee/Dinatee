## Текст для озвучки

**Холодное открытие**  
Я проспал. / Четвёртый день — и всё. ///

**Глава «ОКТЯБРЬ»**  
В октябре я решил бегать. / До моста и обратно — два километра. / Маршрут нарисовал в тетради. // Три утра подряд я вставал в шесть тридцать. / Луна ждала меня у ворот. //

**Глава «ДОЖДЬ»**  
На четвёртый день пошёл дождь. / Будильник я не услышал. /// Проснулся в семь сорок. / И решил: всё, сорвался. //

**Вставка RITM**  
В RITM горели три клетки. / Четвёртая — пустая. / Но пятая ещё не наступила. //

**Глава «КАЛИТКА»**  
Наутро в семь скрипнула калитка. / Луна сидела там. / С поводком в зубах. // Я не побежал. / Просто дошёл до моста. //

**Вставка «КАК НЕ БРОСИТЬ»**  
Тогда я записал правила. / Кроссовки — у двери с вечера. / Сигнал — всегда в семь. / Нет сил бежать — иди. / Два пропуска подряд — нельзя. //

**Глава «СНЕГ»**  
Пятый день. / Восьмой. / Двенадцатый. /// На двенадцатый выпал снег. // И Луна впервые не встала к двери. ///
