# Бункер · Серия 3 «Когда можно выйти» — названия и описание (TikTok)

## Названия (≤ 60 символов)
1. День 14: можно выходить. Одна ошибка — и всё зря — 47
2. Йод из аптечки спасёт от радиации? Нет — 38
3. Когда выходить из укрытия: 5 правил — 35

Рекомендую №1 — повторяет крючок ролика; №2 — для отдельного ролика-мифа.

## Описание
Две недели в подвале позади. По радио: можно выходить. Что делать наверху — по памяткам гражданской обороны:

1. Выходи только по сигналу и иди по маршруту, который назвали.
2. Закрой кожу: длинные рукава, шапка, перчатки; рот и нос — маской или тканью.
3. Обходи пыль и обломки, ничего не трогай. Огород и открытую воду — только после проверки.
4. Йод из аптечки пить нельзя. Йодистый калий защищает только щитовидку — и только по указанию врачей.
5. Вернулся — одежду в пакет и в душ. Питомца помыть водой и вычесать.
И проверь соседей.

Итог сериала: зайди внутрь, останься внутри, слушай новости. Выходи — только по сигналу.
Отправь это тому, кого хочешь видеть живым.

Источники: ready.gov, CDC (Potassium Iodide, Radiation Emergencies).
Ролик образовательный, не прогноз и не повод для паники.
